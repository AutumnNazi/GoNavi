# Plugin ecosystem integration contract

This is the implementation coordination contract, not a claim that every capability is shipped. Track tested support in the public guide. No commits, pushes, production deployment, or generated Wails edits by hand.

## Fixed product decisions

Trusted third-party code, never in the core UI thread. Per-instance backend process; arbitrary desktop UI in its own Wails process and WebView profile. Embedded UI is bounded declarative data rendered by the host. A panel may instead carry bounded custom HTML behind the explicit `ui.html-panel` permission; the host renders it only inside an opaque-origin main-window iframe with no same-origin access, blocked page network/subresource channels and no bridge. The core manager always accepts disable: revoke contributions/calls immediately, persist intent, cancel requests, allow at most two seconds of cleanup, then kill/reap the process tree. Generation fencing prevents stale responses resurrecting contributions. Startup is asynchronous; crash does not restart in a loop. Marketplace failures never block local controls. Full marketplace website is later; current scope includes app marketplace and real shared service. Official results first, real ratings, manual approval for every community version; sideload/private sources remain available.

## Manifest v1 (gonavi.plugin.json)

JSON names: schemaVersion:1, apiVersion:1, id (publisher.name, lowercase ASCII segments), name, version (semver), description?, author?, license?, minHostVersion?, permissions:string[], permissionNotes?:{declaredPermission:plainText<=160}, requires?:[{id,minVersion?,optional?}], backend?:{default?:Entry,platforms?:{["windows/amd64"|"linux/amd64"|...]:Entry}}, contributes?:{commands?:Command[],panels?:Panel[],dataSources?:DataSource[],skills?:Skill[],aiProviders?:AIProvider[],exporters?:Exporter[]}, window?:{entry,title?,width?,height?}, configSchema?:JSON. Entry={executable:package-relative-path,args?:string[],runtime?:"native"|"node"|"python"}; runtime defaults native. Native commands must resolve within immutable package files, no shell. For node/python the executable is the package-relative script, with explicit interpreter discovery and missing-runtime errors. Never execute anything when inspecting/install-previewing.

Command={id,title,description?,inputSchema?:JSON,effect?:"read"|"write"|"unknown"}. Command IDs are local to plugin; invocation separately carries pluginId. Panel={id,title,body?:UINode,html?:{source}} with exactly one of body/html. UINode={type:"text"|"alert"|"column"|"row"|"button"|"table",text?,title?,children?:UINode[],command?,arguments?:JSON,columns?:{key,title}[],rows?:Record<string,JSON>[]} has no HTML, JavaScript, arbitrary CSS, remote code or expression evaluation. html.source is bounded UTF-8 (256 KiB, no NUL) and requires the declared ui.html-panel permission; the host never inlines or parses it in the main DOM, but renders it in an opaque-origin sandboxed iframe whose CSP blocks page fetch/XHR/WebSocket, external subresources, forms, frames, objects and base changes. Bound nesting/node count/data/text sizes; buttons reference declared commands. Manifest-provided display text is data, host strings use i18n. Skill={id,name,description,entry:package-relative exact SKILL.md, resources?: up to 4 other package-relative .md paths}. Resources are nonempty UTF-8 text companions without NUL. They are not scripts, agent tool descriptors, or prompt injection. DataSource={id,name,dialect:"mysql"|"postgres"|"sqlite",command,defaultPort?,readOnly} requires data.sources. `readOnly:true` keeps protocol v1 (query/metadata only); `readOnly:false` opts into protocol v2 exec/begin/commit/rollback. A read-only source's command effect must be omitted, "read", or "unknown". AIProvider={id,name,command,models:[{id,name,contextWindow,maxOutputTokens}],supportsTools:boolean,supportsImages:boolean} requires ai.providers. Declaring `supportsImages` forwards bounded base64 `data:` images on user messages only (4 per message, 4 MiB decoded each, 24 MiB encoded per request, 32 MiB request frame); the host never fetches remote image URLs. Exporter={id,name,command,extension,contentType,streaming?} requires data.export and renders only a host-supplied materialized query snapshot. `streaming:true` opts into ordered v2 chunks (up to 512 rows per chunk, one zero-row chunk for an empty selection, 512 KiB per chunk/reply, plugin owns framing); absent/false keeps the v1 one-shot envelope and 4,096-row/16,384-cell snapshot caps. Future domain contributions must be negotiated rather than silently advertised if unimplemented.

## Backend JSON-RPC 2.0, newline framed

Host->plugin requests: plugin.initialize({apiVersion:1,pluginId,version,generation,config:{},hostVersion,locale,permissions}) -> {apiVersion:1}; plugin.ping({}) -> {}; plugin.invoke({commandId,arguments}) -> JSON; plugin.shutdown({}) -> {}. Cancellation notification: $/cancelRequest({id}). stdout is protocol only; bounded stderr diagnostics. Host responds to supported plugin->host requests only through a caller-bound gateway (never arbitrary App reflection). SDK handlers must not block the protocol/control reader while long work executes. Native/JS UI processes have independent health monitoring. Default handshake=10s, heartbeat every 1s, 3 missed probes, graceful-stop=2s. Scope contexts to lifecycle/request, do not replay writes.

## internal/plugin API expected by Lead

Options{Root string,HostVersion string,Disabled bool} (extend injectable timers/process options for tests). NewManager(Options)(*Manager,error). Start(ctx context.Context) error loads persisted records and asynchronously starts desired-enabled nonquarantined entries. Close(ctx) error. List() []Status; Inspect(ctx,path string)(Inspection,error); Install(ctx,InstallRequest)(Status,error); SetEnabled(ctx,id string,enabled bool)(Status,error) MUST return without waiting for plugin cooperation; Remove(ctx,id string,purge bool)error; Invoke(ctx,id,command string,args json.RawMessage)(json.RawMessage,error); AssetPath(id,relative string)(string,error) restricts immutable installed files and enabled state.

Inspection={manifest:Manifest,digest:string,sourcePath:string,sizeBytes:number}; InstallRequest={path:string,digest:string,trusted:boolean}. Installation requires the exact inspected digest, then copies/extracts to immutable store and verifies again before activation. Initial install is disabled. Status={manifest:Manifest,digest:string,state:disabled|starting|running|stopping|faulted|blocked,desiredEnabled:boolean,generation:number,lastError?:string,installedAt:string}. Quarantine faults persist to avoid boot loops. Package data/config remain outside immutable files. Defaults are conservative; root file locking and atomic persistence required.

## Wails App API for UI (Lead generates bindings)

All return connection.QueryResult with typed payload in data. PluginList()->Status[]; PluginInspect(path:string)->Inspection; PluginInstall(path:string,digest:string,trusted:boolean)->Status; PluginSetEnabled(id:string,enabled:boolean)->Status; PluginRemove(id:string,purge:boolean)->null; PluginInvoke(id:string,command:string,argumentsJSON:string)->JSON; PluginOpenWindow(id:string)->window operation. PluginRuntimeInfo()->{safeMode:boolean,managementAllowed:boolean,webRuntime:boolean}. Web management mutations are rejected by backend unless the server operator opts in with GONAVI_WEB_PLUGIN_MANAGEMENT=1; the client cannot grant it, and desktop-only dialogs/windows stay unavailable in web sessions.

Marketplace App API: PluginMarketSettings()->{baseUrl:string,authenticated:boolean}; PluginMarketConfigure(baseUrl:string)->settings; PluginMarketCatalog(query:string,sort:string,cursor:string)->CatalogPage; PluginMarketDetail(id:string)->MarketPlugin; PluginMarketRatings(id:string)->Rating[]; PluginMarketRate(id:string,stars:number,body:string,version:string)->Rating; PluginMarketDeleteRating(id:string)->null; PluginMarketLogin()->{verificationUri,userCode,deviceCode,intervalSeconds,expiresIn}; PluginMarketPollLogin(deviceCode:string)->{status:string}; PluginMarketLogout()->null; PluginMarketInspect(id:string,version:string,artifactDigest:string,sourceId:string)->{inspection:Inspection,sourceId,artifactDigest,approvalToken,expiresAt}; PluginMarketCancelInspection(approvalToken:string)->null; PluginMarketInstall(id:string,version:string,digest:string,trusted:boolean,approvalToken:string)->Status. Market consent MUST preview the actual downloaded/inspected package (not market-authored metadata). The host retains at most four short-lived one-use quotes, binding exact source receipt, content and transport digests, ID/version and prior installed digest; token stays transient and is never displayed or logged. Install consumes the approved quote, revalidates source/content, installs disabled, records source provenance, and always releases the temporary archive. UI should use a typed API adapter, import future generated functions (Lead will generate); no hand edits to wailsjs and no fallback direct window.go reflection.

## Shared market service /api/v1

Public GET /plugins?q=&sort=updated|rating|downloads&hostVersion=&platform=&cursor=&limit= (default 24,max100); GET /plugins/{id}; GET /plugins/{id}/ratings; GET /plugins/{id}/versions; GET /plugins/{id}/versions/{version}/artifact?platform= returns immutable artifact descriptor; actual download is separate /artifacts/{sha256}. For fixtures/local development baseUrl points to test instance; no fabricated production catalog/stars.

CatalogPage={items:MarketPlugin[],nextCursor?:string}. MarketPlugin={id,name,description,author,publisherId,official:boolean,version,category?,minHostVersion?,platforms:string[],ratingAverage:number,ratingCount:number,downloadCount:number,updatedAt:string,manifest?:Manifest,artifact?:Artifact}. Artifact={url,sha256,sizeBytes,platform,version}. Rating={userId,pluginId,stars,body,version,updatedAt}. Logged-in PUT /plugins/{id}/rating {stars,body,version}; DELETE same; POST /reports. Official flag is trusted service publisher metadata, never client/manifest-author supplied. Official matches sort first; score sorting uses Bayesian smoothing (weight10,global mean or3) but displays real arithmetic mean. One rating/user/plugin; author cannot self-rate; hidden/deleted ratings excluded transactionally.

Auth: POST /auth/device -> {deviceCode,userCode,verificationUri,intervalSeconds,expiresIn}; POST /auth/device/token {deviceCode} -> pending|denied|expired or {status:"authorized",accessToken,refreshToken?,expiresIn}; browser GitHub OAuth minimal login/consent pages; session/revocation API. Admin/publisher tokens only assigned by explicit deployment/bootstrap or account roles; never auto-admin first signup. No production secrets or hardcoded credentials. Local tests use injected identity adapters, not fabricated OAuth success.

Publishing: POST /submissions (authenticated publisher, prebuilt package); GET own /submissions; admin review API approve/reject/yank with audit. Every version: draft->submitted->validating->pending_review->published|rejected; released bytes/version cannot change. PostgreSQL store with migrations; local filesystem artifact adapter for dev, S3-compatible production adapter/config. Public read and write/admin privileges separated. Initial service needs CLI/API admin tooling, not a complete website. Uploaded packages are validated without executing them. API errors are structured {code,message}; log no tokens, SQL/connection data.

## Acceptance

Use crash/hang/ignore-cancel/flood fixtures to prove disabled contributions immediately disappear, UI and core queries stay responsive, processes eventually reaped, new generations do not run old commands, busy never rejects disable, no unbounded automatic restart. Test schema/path/archive limits, permission escalation, official spoof, unauthorized publish/review, rating uniqueness/races, offline market, atomic rollback and all six locale keys. Use real bounded local subprocesses, fake/httptest external services, temp data only. No external production connections. Every implementation must report tested vs unimplemented capabilities clearly.
