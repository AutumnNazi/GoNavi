# 权限参考

清单里的 `permissions` 必须是宿主认识的字符串。下面这些是宿主**实际强制**的权限；写成别的字符串不会被拒绝，但也不会带来任何能力。

| 权限 | 授予什么 | 明确不授予什么 |
|---|---|---|
| `ai.skills` | 声明包内 `SKILL.md` 与最多 4 个配套 `.md`，并提供显式读取与 Agent 技能工具 | 不自动注入系统提示，不授权其他工具，不执行脚本 |
| `ai.tools` | 把普通命令暴露为 Agent 工具 | 保留命令（数据源、AI 提供方、导出）不进入目录；有副作用的调用仍需审批 |
| `ai.providers` | 以原生流式方式提供文本／推理／工具调用 | 不回退到其他提供方；宿主只投影用户选中的那条凭据 |
| `data.sources` | 作为 SQL 方言驱动接入连接、查询与元数据；声明 `readOnly:false` 后可执行单条 `exec` 与插件自管理事务 | 批量执行、流式结果与通用传输都不支持；只读源在适配器层强制拒绝写入 |
| `data.export` | 对已物化的选中行或当前页做一次有界渲染 | 不重查数据库，插件看不到目标路径，不覆盖应用存储 |
| `host.log` | 写有界诊断，每秒最多 8 条，绑定当前进程 | 不是通用日志通道；进程退出或换代后拒绝 |
| `host.describe` | 读取**当前进程**的身份 | 不能用参数指定别的插件，也不返回宿主状态 |
| `ui.html-panel` | 在主窗口内以不透明源沙箱 iframe 渲染有界自定义 HTML | 不提供宿主桥接、存储、Cookie、凭据、同源访问、表单或嵌套 frame；CSP 拦截页面 fetch／XHR／WebSocket 与外部资源，但这不是 OS 或网络栈沙箱 |

## 声明与说明文字

- `permissions` 最多 64 项，每项匹配 `^[a-z][a-z0-9._:-]{0,127}$`。
- `permissionNotes` 可选，键必须是已声明的权限；值是不超过 160 字节的纯文本，不能含标记或控制字符。
- 说明文字只是给用户看的解释，**不会**授予权限；它出现在安装预览里，与确切权限并排显示。

## 边界

权限是宿主侧的准入与能力声明，不是 OS 沙箱，也没有 CPU／内存硬配额。原生插件仍以当前账号的权限运行。
