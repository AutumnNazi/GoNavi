# 插件市场来源与聚合浏览

## 浏览能力

- 按启用的市场来源分组展示；同一插件 ID 在不同来源中分别保留，不自动合并。
- 每个来源独立分页，每页最多 24 个插件。上一页/下一页替换当前页，不无限累积卡片。
- 关键词搜索及更新时间、评分、下载量排序作用于当前参与浏览的已启用来源；修改搜索、排序或其他条件后各组回到第一页。
- 每组显示当前页与本页数量，不推算服务端未提供的总数或总页数。
- 单个来源失败仅在该组提示，可单独重试，不隐藏其他来源的结果。
- 支持来源多选、分类多选、官方/第三方身份、平台多选和作者/发布者关键词。不同字段 AND，同一字段多选 OR，筛选发生在服务端分页之前；不提供标签、最低评分或本地安装状态筛选，也不是虚拟列表。

## 目录缓存与请求预算

- 公开目录采用当前客户端会话内的内存缓存，正常结果 2 分钟内可复用；重启客户端后首次进入仍需请求。
- 最多保留 32 页，并以序列化数据的 UTF-16 估算限制在 8 MiB 内；超大页不进入缓存，LRU 淘汰最旧页。不把全部目录放进 localStorage，也不为保留页面而常驻隐藏卡片 DOM。
- 过期结果先显示上次内容，再后台校验；手动刷新绕过有效期，但不会先清空已有卡片。后台失败保留上次内容并明确标记，短暂退避避免连续切换重复重试。
- 相同来源、搜索、排序和游标的并发请求合并；同时最多 4 个目录请求，每个来源最多 1 个；离开页面或条件变化后，尚未发出的过期请求会取消。
- 来源配置或启用状态变化会失效目录缓存，旧在途结果不能回填已失效的缓存。只关闭只读详情不会刷新全部目录。
- 缓存只保存公开目录，不缓存账号状态、管理权限、真实归档检查或安装批准。详情、检查、安装与公开评分仍通过原有来源绑定接口执行。
- 列表中的评分、下载量等公开指标允许短时间延迟；需要立即查看最新数据时使用刷新。分页仍是每来源 24 条，缓存不是虚拟列表，也不代表服务端数据库已经通过大规模压测。

## 多条件筛选协议与兼容

- 来源筛选只决定参与浏览的已启用市场，不修改保存的启用状态；清除来源筛选恢复全部已启用来源。
- 平台默认当前客户端平台；可选择全部平台或多个具体平台。清除所有条件恢复当前平台默认值。
- 分类沿用市场清单能力归类：数据源、AI 提供方、导出器、技能、面板、命令、运维和其他。
- 作者条件匹配作者名称或发布者 ID，大小写不敏感；关键词仍约束名称、ID 和描述。
- 服务端先选取符合平台条件的已发布版本，再应用分类、身份和作者条件，最后分页，不能用当前24条替代全目录筛选。
- 新筛选使用 `filtersVersion=1`，并要求响应 `filterVersion: 1`；不支持的来源明确提示升级或清除条件，不悄悄展示未筛选结果。未设置额外条件时仍走兼容的旧目录接口。
- 分类与平台通过重复的 `categories`、`platforms` 参数表达 OR，`official` 为 official/community，`author` 为关键词；所有字段之间 AND。
- 缓存及游标历史包含全部规范化条件，字段内顺序不改变语义；更改任何条件从第一页开始。
- 私有来源永远不能提供宿主认定的官方插件；其全部发布者在宿主视角属于第三方，不能采信私有市场自报的官方身份。
- 客户端新增 `PluginMarketSourceSearch`，旧 Wails 方法签名保留。市场 API 也需要更新后才能支持完整新筛选；本轮本地实现不等于线上已部署。

## 桌面客户端与市场网站职责

- GoNavi 桌面端只匿名浏览、搜索、读取公开详情/版本/评分，并执行本地安装和更新；不提供市场登录、退出、设备授权轮询、插件上传或评分编辑入口。
- GoNavi-Plugin-Market 网站／服务负责市场账号、发布、管理和评分写入。桌面评分区域只展示公开评价，提供对应来源网站详情页的安全跳转。
- 来源标题不读取账号状态或密钥链。保留来源管理、筛选、缓存、分页以及公开评分的十条分页。
- 安装仍检查真实归档、来源、版本、摘要和权限，并显式确认信任；匿名使用不意味着免除安全确认。
- 本轮只调整 GoNavi。当前已核对的 GoNavi-Plugin-Market 详情页面只读展示评价，网站评分提交界面不在本轮新增；不能把桌面跳转入口视为该网站写入界面已经实现。

## 来源管理

- 默认官方来源为 `https://plugin.gonavi.org`，始终作为输入框真实值显示，不能编辑或删除，但可以停用。
- 可添加、编辑、删除自定义来源，最多保存 32 个来源；新添加来源默认启用，停用来源不参与目录请求。
- 来源需要兼容 GoNavi 市场的 `/api/v1` 协议，不是任意静态 JSON、GitHub 仓库或 npm 包地址。
- 地址会规范化并去重。远程来源要求 HTTPS；HTTP 仅允许本机回环地址。地址不能含账号、密码或查询参数。
- 配置原子保存于配置目录下的 `plugin-market/settings.json`，新增 `sources` 地址与启用状态列表。
- 旧单来源配置自动迁移，保持原联网选择：旧自定义来源继续启用，补入的官方来源默认停用；旧配置明确停用时不会重新联网。
- 删除或停用来源不卸载已安装插件，也不会清除其安装来源记录。

## 来源隔离与兼容

- 桌面目录、详情、版本及评分读取显式绑定已登记的来源 ID，不靠临时修改全局来源执行请求。
- 来源列表中不保存凭据；桌面市场是匿名只读客户端，没有账号会话，也不读写账号安全存储。
- 官方标记仅取决于构建内置的官方地址，私有来源自报的官方标记不会被采纳。
- 安装继续使用真实归档检查和一次性批准令牌。停用/删除来源会废弃待用批准；重新启用不会复活旧来源会话。
- 已安装插件的更新仍校验全局安装来源与内容摘要；聚合卡片只提示相同 ID 已安装，不据此推断当前市场就是安装来源。
- 旧单来源 API 保留；`baseUrl` 仅作为旧接口的代表来源，聚合请求使用显式来源接口。
- Wails 绑定由官方生成器生成；Web RPC 绑定继续传递请求上下文并执行管理权限检查。

## 验证边界

来源迁移、禁用、重新启用与安装来源隔离通过本地 HTTP 测试；应用来源路由及请求取消另有集成用例。浏览器验收使用真实工作台组件和生成的 Wails JS，宿主 API 为测试桩，覆盖独立分页、共享搜索排序、失效来源和配置重载。未以这些测试替代真实私有市场或打包桌面端验收。
